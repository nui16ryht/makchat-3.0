# **App Name**: MakChat

## Core Features:

- Anonymous Login: Allows users to access basic app features and create a username without requiring an email or personal information; profile creation is disabled.
- Email Login: Allows users to log in with their @students.mak.ac.ug email addresses.
- Profile Creation: Users can create profiles with photos, usernames, emails, college information, bio, and relationship status.
- Direct Messaging: Allows users to send direct text messages to each other, with acceptance required before a user can be texted. Supports view-once messages and screenshot notifications.
- Chat Filtering and Reporting: Allows users to filter chats and report inappropriate content or behavior.
- Post Creation: Enables users to create Twitter-like posts with text, images, and videos.
- Social Interactions: Supports likes, comments, reposts, and quote posts on user-generated content.
- Video Upload and Reels: Users can upload videos and view short video reels.
- Stories/Status Updates: Users can post stories/status updates that disappear after a set time.
- Post Filtering: Filter posts to always show the most popular and most recent.

## Style Guidelines:

- Primary color: A medium blue (#5DADE2) will give a clean and friendly impression, aligning to the theme of online communication.
- Background color: Very light blue (#EBF4FA) for a calm and unobtrusive backdrop.
- Accent color: A dark shade of orange (#FF851B) for interactive elements, drawing users' eyes and signalling important features without clashing against the overall theme.
- Body and headline font: 'PT Sans' for both headlines and body text, due to its balance of modernity and legibility, making the UI feel both contemporary and welcoming.
- Use a set of consistent, modern icons to represent different features and actions.
- A responsive layout adapts to desktop, tablet, and mobile devices, providing an optimal viewing experience across all platforms.
- Subtle transitions and animations enhance the user experience, making the app feel polished and engaging.
